# 传统北方山村院落群 · 高精3D数字孪生与全景重构系统

本项目基于实录长达 8 分 54 秒的北方传统山村实景视频（`M2U00577.MPG`），对一处具有典型地域特征的双联六开间夯土大院落群进行了全要素高精度 3D 数字化孪生重构与多维度交互展现。

---

## 🌟 核心建筑与景观特征

1. **双联六开间夯土正房**：
   - 面宽 19.2 米，进深 4.8 米，双坡青瓦大屋顶与白石灰正脊；
   - 7 根水泥空心砌块廊柱（双层红砖基座防潮），西端首柱采用烧结红砖规整叠砌；
   - 西套为风化木门与白灰抹灰窗套，东套为标志性拱券大门与褪色春联纸符；
   - 檐下窗台整齐码放 3.8 米长青瓦垛及柴堆，东侧摆放斜靠木梯与条凳。

2. **西侧紧挨红瓦附房（零缝隙相连）**：
   - 紧贴正房西山墙建立，四坡烧结红机瓦屋顶（四坡斜脊）；
   - 前檐凹进形成工作檐廊，设木板门紧贴砖叠柱，角柱与挑檐木梁支撑。

3. **东厢房与开阔转角夹道**：
   - 依山就势呈 90 度交角，两房之间留有通畅后山通道，通透无杂舍；
   - 西立面设老杉木门、条石门槛与白灰门套；抬高 0.95 米窗台设立直棂木窗；南端展现阶梯状生土残垣与外露木质房梁。

4. **纯正矩形干砌毛石院墙与入户门垛**：
   - 严格正交矩形围护格局，院坝地面平整开阔；
   - 院外设立由大块山石干砌的粗粝毛石围墙与条石压顶；
   - 入户大门两侧设巨石门垛，大门正对西套住宅木板门。

5. **门外连绵长坡缓坡**：
   - 院门外地势为平滑连续向南倾斜延伸的自然山坡缓坡道，仰望院落高挑挺拔。

6. **屋后双层防风林木**：
   - 第一排紧贴后檐缓坡：密植深绿色圆锥形常绿翠柏绿篱；
   - 第二排位于后山坡地：密植高耸挺拔、银白树干与繁密枝桠的高大白杨树群。

## 🚀 快速启动与本地交互体验

无需任何重型编译依赖，仅需浏览器与 Python 即可启动：

```bash
# 启动本地 Web 服务器
python3 -m http.server 8088

# 在浏览器中访问
open http://localhost:8088/index.html
```

### 交互操作说明
- **轨道视角**：鼠标左键拖动旋转，右键拖动平移，滚轮缩放；
- **10 大核心机位**：点击底部浮动导航栏（1~10号按钮）即可一键平滑运镜至对应实景视角；
- **实景对照抽屉**：点击右上角“实景视频对照”展开视频关键帧对照卡片；
- **第一人称漫游**：点击右上角“漫游漫步视角”或按键 `[V]`，使用 `W/A/S/D` 键自由漫步。

## 📹 原始实景视频完整还原说明

为方便在不同计算机上持续基于原始视频（`M2U00577.MPG`, 602 MB）进行逐帧处理与深入研究，视频文件已采用无损分卷（50MB/卷）完整保存在 `video/` 目录下，彻底避开 GitHub 100MB 单文件限制。

### 一键还原完整视频：

**方式一（推荐，跨平台 Python 脚本，自带 MD5 完整性校验）：**
```bash
python3 restore_video.py
```

**方式二（Linux / macOS Shell 脚本）：**
```bash
./restore_video.sh
```

- 还原后目标：`video/M2U00577.MPG` (602.0 MB)
- 校验 MD5：`4824f3c98d06aa97522ce7b3db100ec9`（确保 100% 比特级一致）
